# Online Shop Application – Manual QA Project

## Project Overview
This project represents a manual QA testing practice for an **Online Shop application**.  
The goal of testing was to verify core e-commerce functionalities, identify functional and UI issues, and create clear QA documentation based on testing results.

---

## Scope of Testing
The following functionalities were tested:

- User registration and login
- Product listing and product details
- Search and filtering of products
- Adding products to cart
- Updating product quantities in cart
- Removing products from cart
- Checkout process
- Input field validations
- Error messages and UI behavior

---

## Testing Types
- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing

---

## Test Artifacts
This project includes the following QA documentation:

- Test Plan (DOCX)
- Test Cases (Excel)
- Bug Reports (Excel)
