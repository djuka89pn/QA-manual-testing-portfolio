# Restaurant Application – Manual QA Project

## Project Overview
This project represents a manual QA testing practice for a **Restaurant application**.  
The goal of testing was to verify core restaurant system functionalities, ensure correct order processing, validate calculations, and identify functional and UI issues.

---

## Scope of Testing
The following functionalities were tested:

- Creating new orders
- Adding and removing items from orders
- Updating item quantities
- Order total calculation
- Payment processing
- Order cancellation
- Validation of user inputs
- Error handling and UI behavior

---

## Testing Types
- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing

## Test Artifacts
This project includes the following QA documentation:

- Test Plan (DOCX)

- Bug Reports (Excel)
