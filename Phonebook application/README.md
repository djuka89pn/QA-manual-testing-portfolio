# Phonebook Application – Manual QA Project

## Project Overview
This project represents a manual QA testing practice for a **Phonebook application**.  
The goal of testing was to verify core phonebook functionalities, ensure proper data handling, validate user inputs, and identify functional and UI issues.

---

## Scope of Testing
The following functionalities were tested:

- Adding new contacts
- Editing existing contacts
- Deleting contacts
- Viewing contact details
- Searching contacts
- Validation of input fields (name, phone number)
- Handling duplicate contacts
- Error messages and UI behavior

---

## Testing Types
- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing
