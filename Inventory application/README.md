# Inventory Application – Manual QA Project

## Project Overview
This project represents a manual QA testing practice for an Inventory Management application.
The goal of testing was to verify core inventory functionalities, identify functional and UI issues,
and create clear QA documentation.

## Scope of Testing
The following functionalities were tested:
- Adding new products to inventory
- Updating existing products
- Deleting products from inventory
- Validation of input fields (product code, quantity, price)
- Handling duplicate product codes
- UI behavior and error messages

## Testing Types
- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing

## Test Artifacts
This project includes:
- Test Cases (Excel)
- Bug Reports (Excel)
- Test Plan (if applicable)

## Key Findings
Several functional and validation issues were identified, including:
- Missing validation messages
- Incorrect handling of duplicate product codes
- Unexpected behavior when deleting or updating products
