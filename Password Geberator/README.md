# Password Generator Application – Manual QA Project

## Project Overview
This project represents a manual QA testing practice for a **Password Generator application**.  
The goal of testing was to verify correct password generation based on selected criteria, validate input handling, and identify functional and UI issues.

---

## Scope of Testing
The following functionalities were tested:

- Generating passwords
- Password length selection
- Inclusion and exclusion of character types (uppercase, lowercase, numbers, symbols)
- Validation of minimum and maximum password length
- Handling invalid or missing input
- Copy password functionality
- UI behavior and error handling

---

## Testing Types
- Manual Testing
- Functional Testing
- UI Testing
- Negative Testing
